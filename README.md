## 📌 Overview

An end-to-end machine learning pipeline that predicts customer satisfaction scores. Covers data preprocessing, feature engineering, model training, evaluation, and production deployment — demonstrating a full MLOps workflow.

**Tech Stack:** `Python` `Scikit-learn` `MLOps` `Data Science` `Production Deployment`

---

## 🚀 Getting Started

### Prerequisites

```bash
pip install -r requirements.txt
```

> Requires **Python 3.8+**

### Installation

```bash
git clone https://github.com/Onabanjomicheal/Customer_Satisfaction_Prediction_to_Production.git
cd Customer_Satisfaction_Prediction_to_Production
pip install -r requirements.txt
```

### Run

```bash
python main.py
```
